# Изменения

## 0.2.0

- Суммарная выходная мощность и три датчика мощности АКБ.
- Счётчики энергии заряда и разряда в kWh для панели «Энергия».
- Настройки направления тока и каналов батареи через интерфейс, без удаления устройства.
- Сохранение накопленных значений, исключение пропусков связи и времени простоя.
- Дополнительные тесты физического расчёта, восстановления и ошибок записи.
- Для HA 2026.11+ основной способ установки — встроенный Marketplace.

## 0.1.1

- Единые обозначения «фаза А / фаза В / фаза С» для 16 групп измерений.
- Исправлена опечатка в названии PF выхода.
- Добавлены HACS-метаданные, инструкция, тесты и проверка HACS в GitHub Actions.
- IP устройства больше не задан по умолчанию; ранее сохранённые настройки сохранены.
- Адреса регистров, масштабы и уникальные идентификаторы сущностей не менялись.

## 0.1.0

- Первая версия мониторинга: 66 сенсоров, 23 дискретных состояния, настройка через UI.
- Карточка панели на встроенных элементах Home Assistant.
